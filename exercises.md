# Create Book Exercise

1. Create a folder named `harry-potter`
2. Open the folder in IntelliJ by choosing `Open` not `New Project`
3. Create a git repository
   - verify by checking the Git panel in IntelliJ at the bottom the right menu bar
4. Add a file `chapter-1.md` to the folder
5. Stage and commit that file using this process here:
    - [Commit Your Code](https://github.com/craigmckeachie/yearup-fall2026-notes/blob/main/READMD.md#commit-your-code)
6. View the commit in the Git Panel at the bottom of IntelliJ
7. Add a file for `chapter-2.md` and commit it following the process above
8. Add a file for `chapter-3.md` and commit it following the process above
9. Add `chapter-4.md` and `chapter-5.md` files and use the process to stage each separately and then commit each logic set of work separately
