Here is a collection of review questions based on the course workbook, covering open-ended, fill-in-the-blank, and short-answer formats:

---

### **Open-Ended & Short Answer Questions**

* What is the primary difference between a centralized version control system and a distributed version control system like Git?


* How do developers use "commits" to track changes, and what capabilities do they provide if a bug is introduced or a rollback is needed?


* Compare and contrast the three primary ways to interact with Git—Command Line Interface (CLI), Integrated Development Environment (IDE), and Graphical User Interface (GUI)—highlighting the primary benefit of each.


* Beyond simple cloud code storage, what are some of the collaboration and project management features provided by GitHub?


* Explain the typical local workflow a developer goes through when making changes before pushing them to a remote repository.



### **Practical & Scenario-Based Questions**

* Why is it emphasized in the course exercises to ensure your GitHub repository visibility is set to **public** rather than private?


* If you are working in a team environment and want to share your local commit history and code updates with others, which Git command/action do you perform to send those changes to the remote repository?

* **CLI vs. IDE vs. GUI:** How do the Command Line Interface (CLI), Integrated Development Environment (IDE), and Graphical User Interface (GUI) differ in how they allow developers to interact with Git, and what is a distinct advantage provided by each approach?


* **Standard Git Workflow:** Walk through the typical lifecycle of a Git workflow from a developer's perspective—from obtaining code changes and making local commits to eventually sharing those updates with teammates.


* **IntelliJ File Status Indicators:** When working inside the IntelliJ IDE, what do the colors **green**, **blue**, **reddish-brown**, and **red** signify regarding a file's tracking and version status?


* **Default Branch Naming Evolution:** How did GitHub's default branch naming convention change in October 2020, and why might you still see the legacy name persist in older repositories?


* **IntelliJ Project Configuration:** When initializing a new project and local repository in IntelliJ for the course exercises, what specific Language, Build System, and JDK are required, and what is the specified local directory path based on your operating system?


* **GitHub Monetization & Enterprise Options:** How does GitHub generate revenue as a for-profit company, and why might larger organizations choose to host their own internal GitHub Enterprise Server instead of using public cloud hosting?
